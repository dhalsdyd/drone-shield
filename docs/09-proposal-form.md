# 1. 아이디어 선정 배경

ㅇ **기지방호 현황 — 저가 드론 위협의 구조적 취약점**
- 민간 촬영·정찰·테러 목적 **저가 UAV** 의 기지 주변 침투 사례 증가
- 현행 대응은 **경계병 육안·CCTV 수동 확인·구두 신고**에 의존 → 야간·악천후·광역 활주로 외곽에서 **탐지 지연**(평균 5분 이상 추정)
- 침투 후 **궤적 추적·위협 유형 판별·대응 SOP**가 관제·현장 간 **비동기**로 진행되어 의사결정 지연

ㅇ **군내외 동향**
- 민간: Dedrone, DroneShield 등 **anti-drone** 상용 솔루션 확산 (민간 공항·시설 중심)
- 국방: 기지방호 **다층 경계·스마트 감시** 강화 정책, 드론 대응 훈련 빈도 증가
- 기술: **YOLO 계열 소형체 탐지**, RF fingerprinting, **엣지 AI** 성숙 → 폐쇄망 실시간 추론 가능

ㅇ **공군 5대 임무 정합성**
- 본 아이디어는 **기지방호** 임무에 직접 부합하며, 비행 임무 **연속성(작전지원)** 을 보호하는 상위 안전 체계

ㅇ **지정공모(정비 AI)와의 명확한 분리**
- 동일 팀의 MAINT-AI Lite는 **정비 행정·Write-up** 대상 **문서 AI**이며, 본 과제는 **대공·경계 비전 AI**로 주제·사용자·데이터가 완전히 상이함

# 2. 아이디어 주요 특징 (핵심 기술)

ㅇ **플랫폼 개요 — DRONE-SHIELD 3 Pillar**

| Pillar | 기능 | 핵심 기술 |
|--------|------|----------|
| **Drone Detect** | 비인가 UAV 탐지·궤적·지오펜스 | RF fingerprinting, YOLOv8, Kalman filter |
| **Threat Classify** | 위협등급·침투 깊이·예측 경로 | Rule+ML hybrid, trajectory prediction |
| **Response Playbook** | SOP·유닛 알림·대응 타임라인 | Workflow engine, C2 연동 API |

ㅇ **핵심 기술 특징**
- **멀티센서 융합:** RF 이상 신호 → PTZ 자동 추적 → 영상 AI 확인의 **2단계 검증**으로 오탐 감소
- **지오펜스:** 기지별 **Red/Amber/Green** 구역 사전 정의, 침범 즉시 등급 연동
- **엣지 온프레미스:** 민간 클라우드 없이 부대 내 GPU·엣지 박스에서 ONNX 추론
- **관제 UX:** 지도 기반 궤적·알림·SOP를 **단일 화면**에서 처리 (웹·모바일)

# 3. 아이디어 구체화(현실화) 추진 전략

ㅇ **3단계 프레임: [원인 분석] → [AI 메커니즘] → [단기 실증]**

**1단계 — 원인 분석**
| 원인 | 현상 | 결과 |
|------|------|------|
| 탐지 지연 | 육안·수동 순찰 | 침투 후 대응 |
| 오탐·미탐 | 단일 센서 | 신뢰도 저하·SOP 혼선 |
| SOP 파편화 | 구두·문서 분산 | 대응 시간 증가 |

**2단계 — AI·센서 융합 메커니즘**
- RF 1차 경보 → PTZ/YOLO 2차 확인 → Threat Classify → Playbook 자동 제안

**3단계 — 단기 실증**
- 1개 비행단 **경계 구역** 시범 → 전단 확산

ㅇ **로드맵**

| 단계 | 기간 | 내용 |
|------|------|------|
| PoC | 0~3개월 | 웹·엣지 시제, mock+1구역 실영상 |
| 시범 | 3~12개월 | 1개 비행단 경계 전면 |
| 확산 | 12개월+ | 전 공군 기지 표준 모듈 |

# 4. 아이디어 구체화(현실화)를 위한 세부 방법

ㅇ **센서·인프라 배치**
- **기존 자산 활용:** CCTV·RF 감시 장비에 **엣지 AI 박스** 추가 (전면 교체 불필요)
- **신규:** 활주로 외곽·펜스 라인 PTZ 2~4대 보강 (시범 구역)

ㅇ **Human-in-the-loop 운영**
- AI 탐지 알림 → 관제 요원 **10초 내** 확인/기각 → 확정 시 SOP 자동 전파
- 오탐 피드백을 **재학습 데이터**로 축적 (월 1회 모델 갱신)

ㅇ **연동 시나리오**
- 기지방호 **관제실** 대시보드 ↔ 경계병 **모바일 알림** ↔ PTZ **자동 추적** 연동
- RED 등급 시 **재밍 구역 권고**(정책·법규 준수 하에 운용 매뉴얼 연계)

ㅇ **웹 PoC 시연 (완료)**
- URL: https://dhalsdyd.github.io/drone-shield/
- 화면: 홈 → Drone Detect(지도 궤적) → Threat Classify → Response Playbook

ㅇ **보안**
- 영상·궤적 데이터 **부대 내 저장**, AES-256, 감사 로그 전수 기록

# 5. 기타 아이디어 구체화를 통한 효과 등 기술

ㅇ **정량 KPI**

| 지표 | 목표 |
|------|------|
| 침투 탐지 | **10초 이내** |
| 오탐율 | **8% 이하** |
| 커버리지 | **95%** |
| 대응 의사결정 | **50% 단축** |

ㅇ **유형·무형 효과**

- 침투 대응 **훈련 시나리오 3배** (mock 이벤트 재생)

|--------|------|
| 오탐 (조류·풍선) | 2단계 센서 융합 + HITL |
| 악천후 | RF 우선 경보, 열화상 보조 |
| 민간 드론 오인 | AMBER 등급·신고 SOP 분리 |

ㅇ **팀 역량**
